You are a Senior Software Architect, UI/UX Designer, and Full Stack Developer.

Build a complete production-ready E-Commerce Website with Oracle Database and Google Drive Image Storage.

===================================================
PROJECT OVERVIEW
===================================================

Create an online store similar to a modern marketplace.

The website must be simple, clean, responsive, and optimized for managing approximately 100 products.

Each product contains:

- Product Name
- SKU
- Description
- Category
- Price
- Stock
- 3–4 Product Images

The design should be inspired by Shopee product store layout, but cleaner and more modern.
